# 🔍 FocusThiefDetector

macOS 焦点抢夺检测器 — 实时监控应用焦点切换，识别可疑的焦点抢夺行为。

## 功能

- 📋 **实时记录** 所有应用焦点切换事件（最多 50 条）
- 🔴 **可疑检测** 自动标记间隔 < 1 秒的异常切换
- 🔔 **声音提醒** 检测到可疑抢夺时发出系统提示音
- 🖼️ **真实图标** 显示应用的系统图标，一目了然
- 📌 **悬浮窗口** 始终置顶，高度可调，位置自动持久化
- 🫥 **无 Dock 图标** 以系统托盘模式运行，不占 Dock 空间

## 图标含义

| 图标 | 含义 |
|------|------|
| 🔴 | 可疑焦点抢夺（切换间隔 < 1s） |
| 🔵 | Apple 系统应用 |
| 🟡 | 腾讯系应用 |
| 🟣 | 微软系应用 |
| 🟠 | Google 系应用 |
| 🟢 | 其他第三方应用 |

> 注：当显示真实应用图标时，emoji 图标作为后备方案。

## 编译 & 运行

```bash
# 编译
swift build -c release

# 运行
.build/release/FocusThiefDetector
```

## 打包为 .app

将编译产物放入 `.app` 包结构即可双击运行，详见 `焦点追踪器.app` 目录。

## 系统要求

- macOS 13.0+
- 建议开启辅助功能权限（系统设置 → 隐私与安全 → 辅助功能）
